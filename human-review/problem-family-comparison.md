## 不能从表中推出的结论

- [agent_inference] PF1 的前置位置不自动使其比 PF4 或 PF5 更值得研究；一个低频但干净的 PF1 现象可能不如一个高频、可审计的 PF4 现象有贡献。来源：directions/pressure-point-reframing.md / Main evidence risks；reports/pressure-point-failure-retrospective.md / Retrospective conclusion。
- [agent_inference] PF2 与 PF3 可以共享 state artifact，但不能因共享 instrumentation 而合并；PF2 的 estimand 是 revision-aligned truth，PF3 的 estimand 是 action-dependent sufficiency。来源：directions/pressure-point-reframing.md / DERIVED_STATE_FIDELITY disposition；reports/pressure-point-failure-retrospective.md / Anti-pattern 11。
- [agent_inference] 高 pilot 成本不会自动排除 PF5，低成本也不会拯救只剩应用迁移的方向；第一轮复审已明确 feasibility-only pass 不能支持 novelty 或 contribution。来源：directions/independent-direction-reaudit-decision-package.md / Mandatory pass-gate audit。
